# LinChat → Lobe 风格二开路线图

## 产品约定

- **助理 = NextChat 面具（Mask）**：助理头像、名称、系统提示词和模型配置都复用 Mask 数据结构。
- 首页承担“开始工作”的入口，不再直接展示空白聊天页。
- 保留参考图红框中的核心能力：侧栏收起/通知入口、首页、最近会话、助理列表、主输入框。
- 视觉借鉴 Lobe 的信息层级、留白、圆角和弱边框，但不复制品牌素材。
