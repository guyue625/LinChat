# LinChat 设置页表单系统设计

## 目标

在不改变设置数据与业务逻辑的前提下，统一设置页输入框、下拉框、数字框、滑杆、开关和操作按钮，使其紧凑、清晰并沿同一右边线对齐。

## 视觉规则

- 普通输入框、密码框、下拉框使用 `320px` 宽、`38px` 高。
- 数字输入框保持语义宽度，统一为 `38px` 高。
- 滑杆组件使用 `440px` 宽、`38-42px` 高。
- 设置行预留 `440px` 控件区域；普通表单、开关和按钮靠右，滑杆占满区域。
- 控件统一使用 `6px` 圆角、细边框与低对比表面。
- 输入文字左对齐；数字值右对齐或居中，采用等宽数字。
- 默认和悬停保持克制；编辑/选中使用 LinChat 红，键盘焦点使用蓝色。
- 密码显隐按钮并入输入框组合，不形成两个割裂方块。
- 测试连接使用蓝色状态色，保存使用红色主操作，次要操作使用中性细边框。

## 响应式与可访问性

- `600px` 以下取消固定宽度，表单铺满控件区域。
- 移动端保持至少 `38px` 控件高度和可识别焦点状态，不产生水平滚动。
- 禁用、错误、测试中和成功状态不能只依赖颜色表达。
- 保留现有标签、`aria-label`、键盘操作和数据流。

## 范围

主要调整 `settings.module.scss`、`settings-controls.module.scss`、`input-range.module.scss` 和 `provider-config-editor.module.scss`。必要时仅为组合控件增加样式钩子，不改登录页、聊天页或底层兼容标识。

## 验收

- 桌面端同类控件尺寸一致，控件右边线一致。
- 深色与浅色主题均清晰可读。
- 390px 移动端无横向溢出。
- 设置页相关测试、TypeScript、ESLint 和 Prettier 通过。
