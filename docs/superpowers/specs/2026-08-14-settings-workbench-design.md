# LinChat 设置页 Workbench 设计

## 目标与范围

将现有设置页改造成紧凑、清晰、易操作的 LinChat 控制台，同时支持浅色和暗色主题。视觉采用暗黑科技、奶白文字、红色选择与主操作、蓝色连接与同步状态，吸收 Cindy 的配色规律但不复刻其页面。

本次只改设置页及其直接使用的组件，不修改登录页。用户可见的 `NextChat` 可替换为 `LinChat`；`nextchat_session`、`chat-next-web-store`、`nextchat.sqlite`、`nextchat-sync`、`nextchat-provider` 及上游仓库引用等兼容标识保持不变。

## 页面结构

- 桌面端采用顶部工具栏、216px 一级导航和最大约 960–1040px 的内容区。
- 一级分类固定为：通用、模型与服务商、外观、语音、助理与提示词、数据与隐私。
- 复杂分类使用页面内二级导航：
  - 模型与服务商：服务接入 / 模型目录 / 默认参数。
  - 语音：实时语音 / TTS。
  - 数据与隐私：同步备份 / 导入导出 / 危险操作。
- 移动端用顶部分类选择器替代侧栏；二级导航横向滚动；设置项改为上下布局。

## 组件与视觉

- 新增设置页专用的 `SettingSection`、`SettingRow` 和表单控件组合，避免直接改动全局 `ListItem` 后影响其他页面。
- 设置行采用“标题说明 / 控件 / 状态”三段式布局，不把每个配置项包成大卡片。
- 输入框、选择框、密码框、按钮、开关统一高度、圆角、边框、焦点与禁用状态。
- 滑杆同时提供精确数值输入和恢复默认按钮。
- 红色只用于当前选择、主要操作和错误；蓝色只用于连接、同步、定位等系统状态。
- 危险操作单独成区，清除数据要求二次确认并输入确认词。

## 搜索与导航

- 设置搜索基于显式注册表，每项包含分类、二级页面、标题、关键词和定位 ID，不依赖遍历渲染后的 DOM。
- 桌面端顶部常驻搜索框并支持 `Ctrl/Cmd + K`；移动端使用全屏搜索。
- 结果按分类和二级页面分组。选择结果后切换到目标页面、滚动定位，并高亮目标设置项约 2 秒。
- 无结果时显示相关关键词建议；搜索范围仅限设置项，不搜索聊天记录。

## 保存与反馈

- 主题、字号、开关等低风险设置继续即时生效。
- Base URL、API Key 等凭证先写入组件草稿；“测试连接”使用草稿值但不持久化，“保存更改”验证通过后再一次性写入现有 store。
- 草稿未保存时，切换分类、服务商或离开设置页均提示确认；取消离开后保留输入。
- 字段格式错误在输入框下方显示；连接失败在当前服务商区域显示原因和重新测试入口；普通成功结果使用短暂 Toast。
- 保存失败不清空草稿，并自动定位到第一个错误项。测试和保存过程中禁止重复提交。
- 移动端存在未保存凭证时，在底部显示固定的“测试连接 / 保存更改”操作栏。

## 代码边界

- `settings.tsx` 负责页面骨架、分类路由、二级导航和搜索协调，并逐步拆出设置页专用组件，避免继续扩大单文件职责。
- `provider-config.tsx` 负责服务商字段描述与凭证草稿，不改变现有 provider 枚举和 store 字段含义。
- `model-manager.tsx` 保留现有模型管理能力，只适配新的分区和控件样式。
- `input-range.tsx` 增加数值输入和恢复默认能力，同时保持现有调用兼容。
- 文案继续进入 locale 文件，不在组件内散落中文常量。

## 验收与测试

- 桌面端与移动端均可完成分类切换、二级导航、搜索定位、凭证测试与保存。
- 浅色和暗色主题均具备清晰层级、可读对比度和完整的 hover、focus、disabled、loading、error 状态。
- 测试覆盖搜索注册与定位、凭证草稿/保存/离开保护、即时生效设置、滑杆精确输入和危险操作确认。
- 实现后运行相关 Jest 测试、`yarn lint`，并对主要桌面与移动断点进行视觉检查。

## 明确不做

- 不修改登录页及 Fable 正在处理的人物视觉。
- 不迁移或重命名底层存储键、数据库、同步协议或 provider 兼容标识。
- 不在本次加入新的账号、计费或管理员功能。
